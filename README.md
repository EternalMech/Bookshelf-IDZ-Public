# Между строк · книжная полка

Добавляйте книги, меняйте статус чтения, ищите и фильтруйте свою полку.

## Локальный запуск

Нужны Flutter **3.44.2** / Dart **3.12.2** и Chrome. Версия закреплена в `.fvmrc`.

```bash
flutter pub get
flutter run -d chrome --web-port 5173 --no-web-resources-cdn
```

Для запуска без автоматического открытия браузера:

```bash
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 5173 --no-web-resources-cdn
```

Открыть **http://localhost:5173**. Не менять hostname/порт между запусками:
`localhost` и `127.0.0.1`, а также разные порты — разные браузерные хранилища.
На Mac с FVM вместо `flutter` можно использовать `fvm flutter`.

Для демовхода используйте логин **`demo`** и пароль **`bookshelf`**.
Реальный аккаунт не нужен: не вводите личные данные. Повторный запуск в том же
профиле браузера открывает полку сразу; «Выйти» возвращает форму и не удаляет книги.

## Что реализовано

- Добавление книги с обязательными названием и автором.
- Три статуса: «Хочу прочитать», «Читаю», «Прочитано».
- Поиск по названию/автору и фильтры по статусу, счётчики.
- Удаление с подтверждением.
- Сохранение в браузере; шесть демонстрационных книг только при первом запуске.
- Демовход с локальной проверкой логина и пароля. В браузере хранится только отметка о входе.
- Адаптивный интерфейс на Material 3; состояния загрузки, пустого списка,
  отсутствия результатов, ошибок чтения и записи.

## Проверка

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

Для ручной проверки: войти, добавить книгу, перевести в «Читаю» и «Прочитано»,
найти её в фильтре «Прочитано». Перезагрузить страницу или остановить сервер и
запустить его снова: книга и статус должны остаться. Нажать «Выйти» и снова
войти: полка не должна очиститься.
